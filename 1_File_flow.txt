//We have a 3 area's
//1. Local(Cloned Repo), 2. Stage(Caching Area before commit to Remote), 3. Remote(Gitub Repo)

//The files at the Local machine can be modified or new files can be added
//These files need to go through the staged area before commiting to Local Repo

//To add the file with modification to staging area
git -add <filename>

//To remove the modifications in the file after the previous commit
git restore <filename>

//To commit the files added in staging area to Local Repo
git commit -m "message_for_this_commit"

//To update the changes at Local Repo to Remote repo 
git push -u origin <branch_name>
//Here, -u sets the upstream so that the next time you can use "git push" directly to push into origin/<branch_name>
//You can also avoid setting the upstream by just giving "git push origin <branch_name>"
