# VSCode Git Configuration

## Changing the Default Terminal

To change the default terminal in VSCode:

1. Open Settings (Ctrl+, or Cmd+, on Mac)
2. Search for "terminal default window"
3. Select your preferred terminal

Note: Preferred one is Git Bash

## Viewing the .git Folder

To make the `.git` folder visible in your workspace:

1. Open Settings
2. Search for "exclude"
3. Remove `.git` from the exclusion list
